# રિમોટ વિડિયો કંટ્રોલ (Remote Video Control)

એક **નવા Android ફોન** વડે બીજા ફોનમાં વિડિયો ચલાવો અને તેને કંટ્રોલ કરો.

- 🎮 **નવો ફોન = કંટ્રોલર** → ગેલેરીમાંથી વિડિયો પસંદ કરો + **બટન** (Play/Pause, Seek, Volume). અહીં વિડિયો ચાલતો નથી.
- 🎬 **જૂનો ફોન = પ્લેયર** → તેના browser માં **મોટી સ્ક્રીનમાં વિડિયો** ચાલે છે.

> કોઈ server ની જરૂર નથી! બન્ને ફોન સીધા એકબીજા સાથે જોડાય છે (WebRTC / PeerJS).
> GitHub Pages પર host કરવા માટે બનાવેલું છે — ફક્ત આ files:

- `index.html` — મુખ્ય પેજ (રૂમ કોડ બનાવો / જોડાઓ)
- `player.html` — જૂના ફોન માટે પ્લેયર (વિડિયો ચાલે છે)
- `controller.html` — નવા ફોન માટે કંટ્રોલર (ફક્ત બટન)
- `manifest.webmanifest` + `sw.js` + `pwa.js` + icons — એપ ઇન્સ્ટોલ (PWA) માટે

## GitHub Pages પર host કરવું (એક વાર)

1. આ repo ને GitHub પર push કરો.
2. **Settings → Pages → Branch** = `main` → folder = `/ (root)` → **Save**.
3. તમને લિંક મળશે, જેમ કે `https://USER.github.io/REPO/`.
4. બન્ને ફોનમાં આ લિંક ખોલો.

## વપરાશ (Usage)

1. કોઈ પણ ફોનમાં લિંક ખોલો → **"નવો રૂમ કોડ બનાવો"** → 4 આંકડાનો કોડ.
2. **જૂના ફોન**માં → **"હું જૂનો ફોન છું" (Player)** → એ જ કોડ → **▶ શરૂ કરો** (ફુલસ્ક્રીન).
3. **નવા ફોન**માં → **"હું નવો ફોન છું" (Controller)** → એ જ કોડ → બટનથી કંટ્રોલ કરો.

> 💡 જૂના ફોનમાં **Chrome** browser વાપરો (WebRTC માટે). બન્ને ફોન **સમાન Wi-Fi** પર હોય તો સૌથી ઝડપી; નહીં તો internet દ્વારા પણ ચાલે છે.

## શું શું કરી શકાય

- 📁 કંટ્રોલર ફોનની Gallery માંથી વિડિયો પસંદ કરો → પ્લેયર ફોનમાં તરત ચાલે
- ▶ / ⏸ Play–Pause
- ⏪ 10s / ⏩ 10s અને Seek bar
- 🔊 Volume + 🔇 Mute

## 📲 એપ તરીકે ઇન્સ્ટોલ કરો (PWA)

આ હવે **installable વેબ એપ (PWA)** છે — કંટ્રોલર, પ્લેયર કે મુખ્ય પેજ, કોઈ પણ પરથી:

1. પેજ પર **"📲 એપ તરીકે ઇન્સ્ટોલ કરો"** બટન દબાવો (Android/Chrome માં જોવા મળે).
   - કે પછી browser મેનૂ → **"Add to Home screen" / "Install app"**.
2. હોમ સ્ક્રીનમાં એપનો આઇકોન આવશે → ખોલશો તો **પૂરી એપ જેવું** (બિના browser-bar વાળું) ખૂલશે.
3. એક વાર ખૂલેલી એપ **ઇન્ટરનેટ વગર પણ** ખૂલે (service worker કૅશ કરે છે).
4. આખરે વપરાયેલ રૂમ-કોડ અને રોલ એપ **યાદ રાખે છે** — મુખ્ય પેજ પર "એ જ રૂમ ફરી ખોલો" દબાવો.

> iPhone (Safari) માં: Share ⬆️ → **Add to Home Screen**.

## 🌙 બેકગ્રાઉન્ડમાં ચાલે (પેજ ખુલ્લું રાખવું ન પડે)

- વિડિયો પસંદ કરતાં જ **લાઇવ સ્ટ્રીમ** તરત શરૂ થાય છે **અને** સાથે-સાથે સંપૂર્ણ વિડિયો background માં પ્લેયર પર **સેવ થઈ જાય છે**.
- કંટ્રોલરમાં **"✓ સેવ થઈ ગયો"** દેખાય એટલે **કંટ્રોલરનું પેજ બંધ કરી દો** — પ્લેયરમાં વિડિયો એ જ જગ્યાએથી ચાલુ રહેશે (પછી ફરી કંટ્રોલર ખોલો તો Play/Pause/Seek ફરીથી કામ કરશે).
- પ્લેયર ફોનની **સ્ક્રીન બંધ કરો કે બીજી એપ ખોલો — અવાજ ચાલુ રહેશે** (Android/Chrome). Lock-screen પર Play/Pause/Seek ના બટન પણ આવશે (Media Session).
- પ્લેયરમાં સ્ક્રીન ચાલુ હોય ત્યારે Wake Lock વડે સ્ક્રીન પણ બંધ થતી નથી.

> નોંધ: સેવ થઈ રહ્યા દરમિયાન (100% થાય ત્યાં સુધી) કંટ્રોલરનું પેજ સંપૂર્ણ બંધ ન કરો. iPhone માં Safari બેકગ્રાઉન્ડ ઓડિયોમાં મર્યાદિત છે — શ્રેષ્ઠ નિષ્કર્ષ જૂના ફોનમાં **Chrome** વાપરવાનો રહેશે.

## ટેકનિકલ નોંધ

આ **screen mirroring** નથી — પરંતુ તમારા કહ્યા મુજબ **"વિડિયો મોડ"** છે: કંટ્રોલર ફોનમાં ફક્ત બટન, અને પ્લેયર ફોનમાં વિડિયો. વિડિયો પ્લેયરના બ્રાઉઝર પોતે લોડ કરે છે, એટલે કોઈ ભારે streaming server ની જરૂર નથી.

**સ્થાનિક રીતે ચલાવવા** (વૈકલ્પિક): `python3 -m http.server 8080` પછી બ્રાઉઝરમાં `http://localhost:8080`.
