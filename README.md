# રિમોટ વિડિયો કંટ્રોલ (Remote Video Control)

એક **નવા Android ફોન** વડે બીજા **જૂના Android (6) ફોન**માં વિડિયો ચલાવો અને તેને કંટ્રોલ કરો.
નવો ફોન = ફક્ત **બટનો** (Play/Pause, Next, Seek, Volume) — અહીં વિડિયો ચાલતો નથી.
જૂનો ફોન = **મોટી સ્ક્રીનમાં વિડિયો** ચાલે છે.

## કેવી રીતે ચલાવવું (Running)

```bash
npm install
npm start          # server http://0.0.0.0:3000
```

બંને ફોન સમાન વાઇફાઇ/ઇન્ટરનેટ પર હોવા જોઈએ, અને server ની URL (PORT/પ્રિવ્યુ) સુધી પહોંચી શકવું જોઈએ.

## વપરાશ (Usage)

1. કોઈ પણ ફોનમાં મુખ્ય પેજ ખોલો → **"નવો રૂમ બનાવો"** → 4 આંકડાનો કોડ મળે છે.
2. **જૂના ફોન (Android 6)**માં → **"હું જૂનો ફોન છું" (Player)** પસંદ કરો → એ જ કોડ ભરો → **▶ શરૂ કરો** દબાવો (ફુલસ્ક્રીન).
3. **નવા ફોન**માં → **"હું નવો ફોન છું" (Controller)** પસંદ કરો → એ જ કોડ ભરો → બટનથી કંટ્રોલ કરો.

> 💡 કોડ 4 આંકડાનો હોવાથી બે ફોનમાં સરળતાથી ભરી શકાય છે.

## શું શું કરી શકાય

- ▶ / ⏸ Play–Pause
- ⏮ Previous / ⏭ Next (પ્લેલિસ્ટમાં)
- ⏩ Seek (વિડિયોમાં આગળ-પાછળ)
- 🔊 Volume + 🔇 Mute
- ➕ કસ્ટમ વિડિયો લિંક (MP4) ચલાવવી
- 📋 પ્લેલિસ્ટમાંથી કોઈ પણ વિડિયો પસંદ કરવો

## ફાઇલો

- `server.js` — Express + WebSocket server (રૂમ અને ચાલ પ્રબંધન)
- `public/index.html` — મુખ્ય પેજ (રૂમ બનાવો / જોડાઓ)
- `public/player.html` — જૂના ફોન માટે પ્લેયર (વિડિયો ચાલે છે)
- `public/controller.html` — નવા ફોન માટે કંટ્રોલર (ફક્ત બટન)

## મહત્ત્વની નોંધ (About "Screen Share")

જૂના Android 6 ના બ્રાઉઝરમાં સાચા **"screen mirroring"** (નવા ફોનની સ્ક્રીન બીજા ફોનમાં જોઈતી) માટે જરૂરી WebRTC `getDisplayMedia` API ઉપલબ્ધ નથી — જેથી એ રીતે લાઈવ screen-share કરવું શક્ય નથી.
આ એપ પરંતુ તમારા કહ્યા મુજબ **"વિડિયો મોડ"** આપે છે: નવા ફોનમાં ફક્ત બટન, જૂના ફોનમાં વિડિયો. આ મોટા ભાગના ઉપયોગ માટે પૂરતું છે.
