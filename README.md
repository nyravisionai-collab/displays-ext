# રિમોટ વિડિયો કંટ્રોલ (Remote Video Control)

એક **નવા Android ફોન** વડે બીજા ફોનમાં વિડિયો ચલાવો અને તેને કંટ્રોલ કરો.

- 🎮 **નવો ફોન = કંટ્રોલર** → ગેલેરીમાંથી વિડિયો પસંદ કરો + **બટન** (Play/Pause, Seek, Volume). અહીં વિડિયો ચાલતો નથી.
- 🎬 **જૂનો ફોન = પ્લેયર** → તેના browser માં **મોટી સ્ક્રીનમાં વિડિયો** ચાલે છે.

> કોઈ server ની જરૂર નથી! બન્ને ફોન સીધા એકબીજા સાથે જોડાય છે (WebRTC / PeerJS).
> GitHub Pages પર host કરવા માટે બનાવેલું છે — ફક્ત આ ત્રણ files:

- `index.html` — મુખ્ય પેજ (રૂમ કોડ બનાવો / જોડાઓ)
- `player.html` — જૂના ફોન માટે પ્લેયર (વિડિયો ચાલે છે)
- `controller.html` — નવા ફોન માટે કંટ્રોલર (ફક્ત બટન)

## GitHub Pages પર host કરવું (એક વાર)

1. આ repo ને GitHub પર push કરો.
2. **Settings → Pages → Branch** = `main` → folder = `/ (root)` → **Save**.
3. તમને લિંક મળશે, જેમ કે `https://USER.github.io/REPO/`.
4. બન્ને ફોનમાં આ લિંક ખોલો.

## વપરાશ (Usage)

1. કોઈ પણ ફોનમાં લિંક ખોલો → **"નવો રૂમ કોડ બનાવો"** → 4 આંકડાનો કોડ.
2. **જૂના ફોન**માં → **"હું જૂનો ફોન છું" (Player)** → એ જ કોડ → **▶ શરૂ કરો** (ફુલસ્ક્રીન).
3. **નવા ફોન**માં → **"હું નવો ફોન છું" (Controller)** → એ જ કોડ → બટનથી કંટ્રોલ કરો.

> 💡 જૂના ફોનમાં **Chrome** browser વાપરો (WebRTC માટે). બન્ને ફોન **સમાન Wi-Fi** પર હોય તો સૌથી ઝડપી; નહીં તો internet દ્વારા પણ ચાલે છે.

## શું શું કરી શકાય

- 📁 કંટ્રોલર ફોનની Gallery માંથી વિડિયો પસંદ કરો → પ્લેયર ફોનમાં તરત ચાલે
- ▶ / ⏸ Play–Pause
- ⏪ 10s / ⏩ 10s અને Seek bar
- 🔊 Volume + 🔇 Mute

> પસંદ કરેલો વિડિયો supported browserમાં WebRTC દ્વારા તરત **live stream** થાય છે; આખી ફાઇલ upload થવાની રાહ જોવી પડતી નથી અને કોઈ server પર upload થતી નથી. Streaming દરમિયાન Controllerનું પેજ ખુલ્લું રાખો. `captureStream` support ન કરતા browserમાં app આપમેળે chunk-based direct transfer વાપરે છે.

## ટેકનિકલ નોંધ

આ **screen mirroring** નથી — પરંતુ તમારા કહ્યા મુજબ **"વિડિયો મોડ"** છે: કંટ્રોલર ફોનમાં ફક્ત બટન, અને પ્લેયર ફોનમાં વિડિયો. વિડિયો પ્લેયરના બ્રાઉઝર પોતે લોડ કરે છે, એટલે કોઈ ભારે streaming server ની જરૂર નથી.

**સ્થાનિક રીતે ચલાવવા** (વૈકલ્પિક): `python3 -m http.server 8080` પછી બ્રાઉઝરમાં `http://localhost:8080`.
